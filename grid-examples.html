🎨 CSS Grid Examples - Ví dụ thực tế

1. 📱 Card Layout - Responsive Cards

Tạo layout card responsive với auto-fit và minmax:

.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: 20px;
}

2. 📊 Dashboard Layout

Tạo layout dashboard với named areas:

.dashboard {
  display: grid;
  grid-template-areas:
    "header header header"
    "sidebar main main"
    "sidebar stats stats"
    "footer footer footer";
  grid-template-columns: 250px 1fr 1fr;
  grid-template-rows: 60px 1fr 200px 50px;
  gap: 15px;
}

3. 🖼️ Photo Gallery

Gallery responsive với aspect-ratio:

.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 15px;
}

.gallery-item {
  aspect-ratio: 1; /* Tỷ lệ vuông */
}

5. 🧱 Masonry Layout

Layout masonry với các item có chiều cao khác nhau:

.masonry {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 15px;
}

.masonry-item:nth-child(1) { grid-row: span 2; }
.masonry-item:nth-child(3) { grid-row: span 3; }
