🎯 CSS Grid Layout - Hướng dẫn từ cơ bản đến nâng cao

1. Grid cơ bản - display: grid

Đây là ví dụ đơn giản nhất của CSS Grid:

.container {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  grid-template-rows: 100px 100px;
  gap: 10px;
}

2. Grid với các kích thước khác nhau

Cột đầu tiên chiếm 2 phần, các cột còn lại chiếm 1 phần:

.advanced-grid {
  display: grid;
  grid-template-columns: 2fr 1fr 1fr;
  grid-template-rows: auto auto;
  gap: 15px;
}

3. Grid với Named Areas (Vùng đặt tên)

Tạo layout trang web với các vùng có tên:

.layout-grid {
  display: grid;
  grid-template-areas:
    "header header header"
    "sidebar main main"
    "footer footer footer";
  grid-template-columns: 200px 1fr 1fr;
  grid-template-rows: 80px 1fr 60px;
  gap: 10px;
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }
