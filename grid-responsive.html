📱 CSS Grid Responsive - Layout thích ứng

1. 🎯 Mobile First Approach

Bắt đầu với mobile và mở rộng lên các màn hình lớn hơn:

/* Mobile First - Mặc định 1 cột */
.mobile-first-grid {
  display: grid;
  grid-template-columns: 1fr;
}

/* Tablet - 768px+ */
@media (min-width: 768px) {
  .mobile-first-grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Desktop - 1024px+ */
@media (min-width: 1024px) {
  .mobile-first-grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

2. 🔄 Auto-fit với minmax

Tự động điều chỉnh số cột dựa trên kích thước màn hình:

.auto-fit-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 20px;
}

Feature 1

Responsive design with auto-fit and minmax functions.

Feature 2

Automatically adjusts number of columns based on available space.

Feature 3

No media queries needed for basic responsive behavior.

Feature 4

Perfect for card layouts and content grids.

3. 🧭 Responsive Navigation

Navigation chuyển từ dọc sang ngang trên tablet:

/* Mobile - Navigation dọc */
.nav-grid {

}

/* Tablet+ - Navigation ngang */
@media (min-width: 768px) {
  .nav-grid {
    grid-template-columns: repeat(4, 1fr);

4. 📝 Responsive Blog Layout

Layout blog với sidebar trên desktop:

/* Mobile - Single column */
.blog-grid {
  display: grid;
  grid-template-columns: 1fr;
}

/* Tablet+ - Main content + Sidebar */
@media (min-width: 768px) {
  .blog-grid {
    grid-template-columns: 2fr 1fr;
  }
}

Main Article

Đây là nội dung chính của bài viết. Trên mobile, sidebar sẽ hiển thị bên dưới main content. Trên tablet và desktop, sidebar sẽ hiển thị bên cạnh.

CSS Grid giúp tạo layout responsive một cách dễ dàng và linh hoạt. Bạn có thể điều chỉnh tỷ lệ giữa các cột bằng cách thay đổi giá trị fr.

5. 📊 Responsive Dashboard

Dashboard với layout khác nhau cho từng breakpoint:

/* Mobile - Single column stack */
.responsive-dashboard {
  display: grid;
  grid-template-columns: 1fr;
  grid-template-rows: auto auto auto auto;
}

/* Tablet - Sidebar + Content */
@media (min-width: 768px) {
  .responsive-dashboard {
    grid-template-columns: 200px 1fr;
    grid-template-areas:
      "header header"
      "sidebar content"
      "stats stats";
  }
}

/* Desktop - Full layout */
@media (min-width: 1024px) {
  .dashboard-stats {
    grid-template-columns: repeat(4, 1fr);
  }
}

6. 🎴 Responsive Card Grid

Grid card với số cột thay đổi theo breakpoint:

/* Mobile - 1 column */
.responsive-cards {
  grid-template-columns: 1fr;
}

/* Tablet - 2 columns */
@media (min-width: 768px) {
  .responsive-cards {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Desktop - 3 columns */
@media (min-width: 1024px) {
  .responsive-cards {
    grid-template-columns: repeat(3, 1fr);
  }
}

/* Large Desktop - 4 columns */
@media (min-width: 1200px) {
  .responsive-cards {
    grid-template-columns: repeat(4, 1fr);
  }
}

7. 🆕 Container Queries (Modern CSS)

Container queries cho phép responsive dựa trên kích thước container thay vì viewport:

.container-query-demo {
  container-type: inline-size;
}

.container-grid {
  display: grid;
  grid-template-columns: 1fr;
}

@container (min-width: 400px) {
  .container-grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

@container (min-width: 600px) {
  .container-grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

📋 Best Practices cho Responsive Grid

/* 1. Mobile First Approach */
.grid {
  display: grid;
  grid-template-columns: 1fr; /* Mobile default */
}

/* 2. Sử dụng minmax() cho flexibility */
.grid {
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
}

/* 3. Breakpoints phổ biến */
@media (min-width: 768px) { /* Tablet */ }
@media (min-width: 1024px) { /* Desktop */ }
@media (min-width: 1200px) { /* Large Desktop */ }

/* 4. Sử dụng gap thay vì margin */
.grid {
  gap: 20px; /* Thay vì margin */
}

/* 5. Named areas cho complex layouts */
.layout {
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}
