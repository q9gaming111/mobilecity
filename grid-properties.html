🔧 CSS Grid Properties - Thuộc tính chi tiết

📋 Thuộc tính Container (Grid Container)

1. Thuộc tính cơ bản

Thuộc tính Mô tả Ví dụ
display Kích hoạt Grid Layout display: grid;
grid-template-columns Định nghĩa số cột và kích thước grid-template-columns: 1fr 2fr 1fr;
grid-template-rows Định nghĩa số hàng và kích thước grid-template-rows: 100px auto 200px;
gap Khoảng cách giữa các grid items gap: 20px;
grid-gap Khoảng cách (cách viết cũ) grid-gap: 20px;

2. Đơn vị đo trong Grid

/* Các đơn vị đo phổ biến */
grid-template-columns: 200px; /* Pixel cố định */
grid-template-columns: 1fr 2fr 1fr; /* Fractional units */
grid-template-columns: auto; /* Tự động điều chỉnh */
grid-template-columns: minmax(200px, 1fr); /* Min/Max */
grid-template-columns: repeat(3, 1fr); /* Lặp lại */

3. Ví dụ minmax() và repeat()

minmax(): Định nghĩa kích thước tối thiểu và tối đa

.minmax-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 15px;
}

2. align-content (Căn chỉnh theo chiều dọc)

Giá trị Mô tả
start Căn về đầu
center Căn giữa
end Căn về cuối
space-between Phân bố đều, không có khoảng cách ở đầu/cuối
space-around Phân bố đều với khoảng cách bằng nhau
space-evenly Phân bố đều với khoảng cách hoàn toàn bằng nhau

📦 Thuộc tính Grid Items

1. grid-column và grid-row

/* Span qua nhiều cột/hàng */
.item {
  grid-column: span 2; /* Chiếm 2 cột */
  grid-row: span 2; /* Chiếm 2 hàng */
}

/* Định vị cụ thể */
.item {
  grid-column: 2 / 4; /* Từ cột 2 đến cột 4 */
  grid-row: 1 / 3; /* Từ hàng 1 đến hàng 3 */
}

2. Thuộc tính căn chỉnh cho items

Thuộc tính Mô tả Giá trị
justify-self Căn chỉnh item theo chiều ngang start, center, end, stretch
align-self Căn chỉnh item theo chiều dọc start, center, end, stretch
place-self Viết tắt của justify-self và align-self center, start end, etc.

🎨 Named Grid Lines (Đường lưới có tên)

.named-lines-grid {
  display: grid;
  grid-template-columns: [start] 1fr [middle] 1fr [end];
  grid-template-rows: [top] 100px [center] 100px [bottom];
}

.item {
  grid-column: start / end;
  grid-row: top / bottom;
}
